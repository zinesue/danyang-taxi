### 복귀비 포함 잔액과 계획 완료 (2026-11-07)

- 배포 빌드의 `/danyang-taxi/`에서 모바일 360×640·390×844 및 PC 1440×900 화면을 확인했습니다. 대시보드는 `방문비 / 복귀비 / 남은 예산` 순서로 유지됩니다.
- 4만원에서 `삼봉로 123` 조회 중 대시보드는 `0 / 0 / 40,000원`, 후보는 `확정 후 남은 예산 31,200원`을 표시합니다. 확정 직후 대시보드는 `4,400 / 4,400 / 31,200원`입니다.
- `삼봉로 145 → 167 → 189`를 추가했습니다. 네 방문 확정 후 `17,600 / 4,400 / 18,000원`이 표시되며, 완료·새로고침·완료 취소 후에도 같은 금액입니다. 전체 경로는 완료 시 자동으로 펼쳐지고, 방문 4곳과 별도로 마지막에 `소노길 복귀 4,400원`을 표시합니다. 완료 시 총 1.8km·택시 5회입니다.
- 세 방문 상태의 예산을 2만원으로 줄이면 잔액 2,400원, 다음 후보는 2,000원 부족으로 확정이 차단됩니다. 네 방문 확정 후 2만원으로 줄이면 잔액 -2,000원 및 부족 안내, 완료 버튼 비활성화를 확인했습니다.
- 완료 취소 후 마지막 방문을 되돌리면 `13,200 / 4,400 / 22,400원`으로 복원됩니다. 다시 완료하면 방문 3곳·복귀 1구간·택시 4회가 표시됩니다.
- 작은 화면에서는 하단 패널만 스크롤되며 지도 영역을 유지합니다. 새로고침 중 외부 배경지도 오류 안내가 한 번 표시됐으나 금액과 경로는 정상 복원됐고, 현재 계획 위치로 이동한 뒤 지도 표시를 확인했습니다.

## 데이터와 성능

### 주소 검색 추가 검증

- 출입구 14,873개는 주소 필드가 없어 미적용. 기초구간 64,607개 중 단양군 64,602개만 포함(인접 시군 5개 제외), 도로명 연결 누락 0개.
- 632개 도로명, 64,603개 선 부분, 128,922개 서로 다른 기초번호 조합. 복수 위치가 있는 번호 282개는 후보를 분리하며 최대 3개 위치입니다. 이 수치는 건물·출입구 수가 아닙니다.
- 전체 64,603개 출력 위치를 원본의 `SIG_CD + RDS_MAN_NO + BSI_INT_SN`으로 역대조했습니다. 행정구역, 도로명, 홀/짝 본번·부번이 일치하고 출력 좌표가 원본 선에서 0.02m 이내임을 확인했습니다. 이는 좌표 변환·반올림 검증이며 주소 추정 정확도를 뜻하지 않습니다. `BSI_INT_SN` 단독은 원본에서 중복되므로 식별 키로 사용하지 않습니다.
- 주소 인덱스 gzip 986,664바이트, 압축 해제 시 3,652,622바이트. 외부 주소 API 요청은 없습니다.
- 배포 빌드에서 전체 주소 `충청북도 단양군 단양읍 삼봉로 123` 검색 → Enter → 방문·복귀 각각 916m / 4,400원 표시, 방문 확정 및 새로고침 후 주소명과 원본 구간 정보 복원을 확인했습니다. 초기 버전의 `(도로 추정)` 문구는 이후 공간 조정에서 제거했습니다.
- `용부원2길 30-2`의 두 후보 표시와 초기 Enter 자동 선택 방지, 위쪽 방향키로 마지막 후보 선택을 확인했습니다. `삼봉로 999999`는 결과 없음으로 안내합니다.
- 모바일 390×844, 360×640에서 `상선암길 52-8` 검색 결과와 추정 안내를 확인했습니다. PC 1440×900에서도 같은 검색과 하단 대시보드를 사용합니다.
- 배포 주소 파일을 일시적으로 없앤 404 상황에서 검색 오류와 재시도 버튼이 나타나고, 지도 선택의 경로·요금 조회는 계속 동작했습니다. 파일 복원 후 재시도로 검색이 정상 복구됐습니다.

- 연결 성분: **36 → 30개**.
- 노드 5,099개, 엣지 5,680개. 주 성분 4,979개 노드, 약 1,210.703km.
- 선형 총합 약 1,281.898km(중복 선형 포함 가능).
- 보정 기록: 1cm 초과 접촉 병합 200건, 접근 검토 후보 7건. `public/data/topology-repairs.json` 참고.

- 이번 테스트 런타임에서 그래프 초기화 약 38ms, 예산별 도로 범위 계산 약 20~33ms. 다운로드·지도 렌더링 시간 제외, 기기별 성능 보장 아님.
